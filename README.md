# Samuel Lefcourt — Thesis Defense Website

This is a simple static site intended for GitHub Pages.

## What to change

- `index.html`: replace placeholders in the **Thesis** and **Contact** sections
- Add real links for your thesis PDF / slides / recording

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Put these files in the repository root (including `index.html`, `styles.css`, `404.html`).
3. In the repository settings, enable **GitHub Pages** for the appropriate branch/folder.
